# World Models and Latent-State Learning — Foundation Research for SPM

## Status

Research synthesis. This note asks which existing neural architectures already demonstrate persistent learned state, imagined rollouts, selective recurrence, entity-centric slots, and compositional latent structure—and where those ideas stop short of semantic/pragmatic cognition.

## 1. World models demonstrate that learned latent state can be causally useful

Ha & Schmidhuber's *World Models* work showed that an agent can learn a compressed spatial/temporal latent representation of an environment and use that learned model to support a compact policy. The striking result was not merely compression: policy learning could occur inside trajectories generated by the learned world model and transfer back to the environment.

That is a strong precedent for SPM because it establishes a general architecture pattern:

```text
observation -> learned latent state/dynamics -> imagined consequences -> policy/action
```

The learned state is not decorative. It participates causally in behavior.

### Sources

- Ha & Schmidhuber, *World Models* / *Recurrent World Models Facilitate Policy Evolution*, NeurIPS 2018: https://worldmodels.github.io/
- arXiv:1803.10122 / 1809.01999

## 2. Dreamer strengthens the case for latent state as a planning substrate

Dreamer-family agents learn a world model from experience and improve behavior using imagined future scenarios. DreamerV3 demonstrated one configuration across a broad set of control domains, and the 2025 Nature paper reports strong performance across more than 150 tasks.

**SPM implication:** a learned internal state does not need to mirror every surface observation to be useful. If it predicts action-relevant consequences and supports planning, a compressed latent state can be a legitimate computational substrate.

But this is not yet semantic/pragmatic state. Control world models are optimized around environment dynamics and reward-relevant prediction, not proposition identity, discourse reference, speech acts, provenance, or common ground.

### Source

- Hafner et al., *Mastering diverse control tasks through world models*, Nature 640, 647–653 (2025), DOI: 10.1038/s41586-025-08744-2

## 3. SPM should borrow the causal criterion, not the name 'world model'

A tempting but sloppy move would be to call any persistent SPM state a `world model`. That is too broad.

SPM needs to represent at least several different frames:

```text
CURRENT_WORLD_HYPOTHESIS
DISCOURSE_SITUATION
BELIEF_OF_PARTICIPANT_X
HYPOTHETICAL_WORLD
QUOTED/FICTIONAL_WORLD
PRAGMATIC_INTERACTION_STATE
```

A single undifferentiated world-model vector could make these frames harder, not easier, to keep distinct.

The useful inheritance is instead:

> learned state should predict and constrain downstream consequences, and interventions on that state should alter behavior in expected ways.

## 4. State-space models prove efficient recurrent sequence state remains competitive

Structured State Space Models and Mamba provide a modern alternative to keeping the entire past available through full self-attention. Mamba makes state-space parameters input-dependent, allowing the model to selectively propagate or forget information along the sequence, while retaining recurrent linear-time inference.

This matters because SPM's persistent state may need to operate over long-running interaction without replaying an ever-growing prompt.

**SPM implication:** recurrent/fixed-size state is architecturally plausible at language scale. Selective state updates offer a concrete mechanism family for deciding what information persists.

**Non-implication:** Mamba's state is not thereby an explicit semantic state. It is trained as a general sequence-model state and can remain opaque and entangled.

### Source

- Gu & Dao, *Mamba: Linear-Time Sequence Modeling with Selective State Spaces*, arXiv:2312.00752, DOI: 10.48550/arXiv.2312.00752

## 5. Selective recurrence is especially relevant to correction and salience

Mamba's central architectural idea—input-dependent propagation/forgetting—suggests a broader SPM research question:

> Can learned update gates decide which semantic/pragmatic variables should persist, revise, split, or become inactive after each observation?

Candidate update classes might include:

```text
PRESERVE
REVISE
SUPERSEDE
CREATE_NEW_ENTITY
SPLIT_HYPOTHESIS
MERGE_HYPOTHESES
DEACTIVATE_FROM_CURRENT_FRAME
RETAIN_AS_HISTORY
```

A learned gate could implement these operations in distributed state without requiring symbolic instructions. The operations themselves provide evaluation targets.

## 6. Object-centric learning offers a precedent for entity-like latent slots

Slot Attention transforms perceptual features into a set of exchangeable task-dependent `slots` that can bind competitively to objects. The method demonstrated object-centric representations and generalization to unseen compositions.

This is highly relevant to SPM's entity/referent problem. An SPM could investigate learned slots that bind to discourse entities, propositions, events, participant perspectives, or unresolved hypotheses.

### Source

- Locatello et al., *Object-Centric Learning with Slot Attention*, NeurIPS 2020, pp. 11525–11538: https://papers.nips.cc/paper/2020/hash/8511df98c02ab60aea1b2356c013bc0f-Abstract.html

## 7. Object slots are not automatically discourse referents

Visual object-centric methods normally assume that useful latent factors correspond roughly to persistent objects or scene components. Language creates harder cases:

- one entity has many names/descriptions;
- one description can refer to different entities across contexts;
- propositions/events are not physical objects;
- quotations introduce speaker-relative entities;
- hypothetical entities may never exist in the current world;
- a single entity can participate in multiple concurrent role structures.

**SPM implication:** slot-based state is a mechanism candidate, not the ontology. Binding rules need discourse, source, scope, time, and frame information.

## 8. Graph representations are natural for relational meaning but risk brittle bottlenecks

Entity/proposition/event state is inherently relational. Learned graph representations or graph neural networks could make relations such as `speaker-of`, `causes`, `before`, `believes`, `refers-to`, `supersedes`, and `member-of-hypothesis-set` directly accessible.

But forcing all meaning through a discrete graph can fail when:

- relevant structure is not known in advance;
- relations are graded or uncertain;
- the ontology is incomplete;
- subtle pragmatic meaning is difficult to discretize;
- parser errors poison all downstream computation.

SPM should therefore compare explicit graphs, latent slots, and distributed recurrent state rather than assuming graph structure is inherently superior.

## 9. Persistent memory architectures raise a key distinction: storage versus cognition state

Many neural and agent architectures attach external memories to a model. Retrieval can greatly extend effective context, but retrieval memory and active semantic state are different objects.

SPM should distinguish:

```text
LONG_TERM_STORAGE
RETRIEVED_EVIDENCE
ACTIVE_INTERPRETATION_STATE
WORKING_HYPOTHESES
LEARNED_PARAMETRIC_KNOWLEDGE
```

A database record does not become current situation state merely because retrieval surfaced it. This directly addresses history/currentness collapse in LLM systems.

## 10. Latent-state learning must preserve intervention semantics

A state vector can predict well while being impossible to interpret or edit reliably. For SPM, prediction alone is not enough if the research claim is that semantic/pragmatic state is first-class.

At minimum, we need tests showing that specific intervention classes have stable effects:

- change a referent binding -> dependent answers/actions change;
- supersede proposition P -> later reasoning stops using P;
- preserve two ambiguity branches -> later evidence selects the right branch;
- alter participant-belief state -> pragmatic prediction changes without changing world-truth state;
- change modality/time/source -> proposition consequences change appropriately.

This bridges world-model research to the later causal-representation research program.

## 11. Candidate SPM latent architecture families

### A. Recurrent situation state

A recurrent learned state updated once per discourse/event unit, with language generation conditioned on the state.

### B. Structured slot state

A variable set of entity/event/proposition slots plus relation/binding modules.

### C. Hybrid graph-latent state

Discrete or semi-discrete typed nodes/relations with learned continuous node state.

### D. Selective state-space backbone

A Mamba/SSM-like recurrent backbone plus supervised semantic/pragmatic projections and intervention hooks.

### E. Dual-level state

Opaque high-capacity recurrent latent state plus a smaller typed semantic/pragmatic interface whose contents are causally fed back into inference.

The last option may avoid forcing the entire cognition substrate through a brittle human-designed representation while still making key distinctions explicit.

## 12. Falsifiable experiments

### A. Persistent state versus long-context replay

Match model size/data/compute. Compare a recurrent learned state against a transformer given full conversational history. Test referents, corrections, temporal state, and long-task coherence.

### B. Slot binding for discourse entities

Track multiple similar entities through aliases, pronouns, role changes, quotations, and hypothetical frames. Compare slot/entity state against ordinary attention-only baselines.

### C. Selective state revision

After a correction, require one variable to change while unrelated state remains stable. Measure both under-update and catastrophic over-update.

### D. Imagined pragmatic consequences

Given candidate interpretations of an ambiguous utterance, predict likely conversational/action consequences before choosing a response. Compare with direct next-response decoding.

### E. Intervention test

Directly perturb one learned state component and verify specific downstream behavioral effects. A state that can be decoded but not causally manipulated does not satisfy the strongest SPM claim.

### F. Compression stress test

Hold active-state capacity fixed while dialogue length grows. Test whether important referents, unresolved contradictions, corrections, and current task state survive better than prompt-only baselines.

## 13. Foundation conclusion

World-model research contributes the proof that **learned latent state can be a causal planning substrate**. State-space models contribute **efficient selective recurrence**. Object-centric learning contributes **learned exchangeable binding slots**. Graph/persistent-memory work contributes **relational structure and timescale separation**.

The synthesis for SPM is not `build a world model for conversation`. It is:

> **Build and test learned recurrent meaning-state whose contents are selected by semantic/pragmatic relevance, preserve entity and hypothesis structure, and causally constrain later reasoning and action.**

That is a plausible model architecture research program—and importantly, every mechanism can be compared against a matched modern LLM rather than assumed necessary.
