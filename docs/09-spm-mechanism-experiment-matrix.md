# SPM Mechanism Experiment Matrix

Status: EXPERIMENT SEQUENCING / NOT QUALIFICATION
Date: 2026-09-15

## Purpose

Test the convergent architecture without turning it into an inseparable stack. Every mechanism must produce a matched causal advantage before becoming part of the qualified architecture.

## Stage 0 — frozen controls

Before any SPM training, freeze:
- exact backbone and tokenizer subjects;
- public development and blind-holdout identities;
- train/eval material digests;
- trainable-parameter, token, step, FLOP, memory, and inference budgets;
- ordinary-competence floors;
- lifecycle/isolation contract and result-manifest schema.

No later stage may repair a losing result by changing these controls after seeing outcomes.

## Stage 1 — persistence × relational representation

Run a 2×2 matched experiment:

| State form | transient/reset | persistent/reinjected |
| --- | --- | --- |
| vector | V0 | V1 |
| hyperconnectome | H0 | H1 |
Primary effects:
- persistence = V1−V0 and H1−H0;
- relational structure = H0−V0 and H1−V1;
- interaction = whether persistent hyperconnectome gains exceed additive effects.

Required interventions: lesion, freeze, scramble, matched state substitution, decoder ablation, and no-extra-context control.

Kill persistence if persistent variants do not reproducibly beat their reset equivalents or if interventions do not causally affect behavior.

Kill hyperconnectome structure if H variants do not beat parameter/compute-matched vectors or if gains disappear under capacity matching.

## Stage 2 — timescale separation

Only the best surviving Stage-1 state form proceeds. Compare one recurrent state against fast+slow state with matched trainable parameters, recurrent depth, and inference budget.

The slow state must update under a frozen gate/policy rather than receiving privileged labels unavailable to the single-state control.

Kill timescale separation if it does not improve long-horizon correction, referent, authority, and behavioral-recovery tasks without worsening warranted adaptation.

## Stage 3 — explicit semantic/provenance plane

Compare the surviving neural state alone against the same neural state plus an explicit graph containing exact propositions, provenance, supersession, authority, and contradiction state.
The graph may expose structured facts/relations but may not inject answer labels or hidden holdout information.

Kill the explicit plane if it fails to improve contradiction/currentness/provenance behavior enough to justify latency, complexity, and failure surface.

## Stage 4 — adaptive cognitive routing

Compare always-cheap, always-deep, and adaptive routing at matched aggregate compute. Route choices may include direct generation, state revisit, hierarchical retrieval, symbolic verification, and hypothesis branching.

Adopt adaptive routing only if it lies on a better accuracy/cost/latency frontier than fixed policies. A faster router that lowers correctness fails; a more accurate router that simply spends more compute also fails.

## Stage 5 — retrieval and geometry

Hierarchical retrieval and non-Euclidean geometry remain later hypotheses. Test tree navigation against flat/vector/full-context retrieval under equal corpus access. Test hyperbolic geometry against Euclidean representations only after the state mechanism itself has survived.

Probe separability alone is not causal evidence.

## Promotion rule

A mechanism enters the qualified SPM architecture only after:
1. exact-subject matched improvement;
2. causal intervention evidence where applicable;
3. unseen-transfer retention;
4. ordinary-competence floors;
5. resource/deployment qualification;
6. independent hostile review of the exact candidate.

A later mechanism may not be used to rescue an earlier failed mechanism. Negative results remain first-class program outcomes.
